# Western Classic 2027

Event site for the Trelawny Gun Club Western Classic, Sunday, April 18, 2027.

Static site: `index.html` plus `assets/tgc-logo.png`. No build step.

## Publish on GitHub Pages
1. Create a repo under the TrelawnyGunClub organisation (e.g. `western-classic`) and upload everything in this folder.
2. Repo Settings, Pages, Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site goes live at `https://trelawnygunclub.github.io/western-classic/`.

## Fill in later
Open `index.html` and edit the `SITE` block near the bottom:
- `registrationUrl`: turns the Register buttons live.
- `sponsorEmail` or `sponsorWhatsApp`: turns every sponsor slot and the "Ask about sponsoring" button into a contact link.

Venue, format, start time, entry and prizes are marked "To be announced" in the Event section.
